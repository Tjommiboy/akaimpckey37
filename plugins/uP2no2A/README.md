# uP2no2A (v0.1.0, effect, uid `UJFy`)

An electro-optical tube leveling amplifier for the MPC, in the spirit of the classic 1960s two-knob
leveler. By uP2noGood. Original DSP and artwork (MIT); nothing is copied from any other product.

## Pages

**FRONT** is laid out like the hardware faceplate, left to right:
LIMIT / COMPRESS toggle and POWER toggle with lamp, big GAIN knob, VU meter, big PEAK REDUCTION
knob, METER selector (+10 / GAIN REDUCTION / +4).

**REAR** holds what the original keeps on the back: HF EMPHASIS (the R37 trim) and STEREO LINK,
plus OUTPUT TRIM (parameter 0; not on the original).

Q-Links (one bank per page): FRONT = Gain, Peak Reduction, Limit/Compress, Meter.
REAR = Emphasis, Stereo Link, Output Trim.

## Using it

1. Turn PEAK REDUCTION up until the meter (set to GAIN REDUCTION) dips 3 to 7 dB on loud parts.
2. Bring the level back with GAIN (40 = unity). Pushing GAIN adds tube-style saturation.
3. COMPRESS is gentle with a soft knee (about 4:1 to 5:1 on a sine); LIMIT is much steeper (about 20:1).
4. HF EMPHASIS at FLAT treats all frequencies alike. Turn it towards HF so bass triggers less
   reduction (bass-heavy material, drum bus).

There are no attack or release controls, as on the original. Attack is about 10 ms. Release is in
two stages: about half the reduction is gone in 60 ms, the rest takes 0.5 s to several seconds and
gets slower the longer and harder it has been working.

## Parameters (order and ids are permanent)

| # | Name | Range | Note |
|---|---|---|---|
| 0 | Output | -12..+12 dB | trim after everything |
| 1 | Peak Red | 0..100 | 0 = threshold about 0 dBFS, 100 = about -40 dBFS |
| 2 | Gain | 0..100 | 40 = unity, 100 = +30 dB |
| 3 | Mode | Compress / Limit | |
| 4 | Meter | +10 / GR / +4 | 0 VU = -12 dBFS (+10) or -18 dBFS (+4) |
| 5 | Emphasis | 0..100 | 100 = flat |
| 6 | Stereo Link | on/off | off = one cell per channel |
| 7 | Power | on/off | off = bypass, meter drops |
| 8 | VU | display only | written by the plugin to move the needle; do not automate it |

## Honest notes

- Not yet tested on an MPC. To check first: the VU needle moving live (it uses the same "notify the
  host" method that worked for Contour EQ, with one parameter instead of 160), the big film-strip
  knobs (160 x 11200 px), and the three-position METER knob.
- "VU" appears in the automation list because the MPC only redraws automatable parameters. Recording
  automation while it moves will record the needle; leave it out.
- One voice only (no Silver / Gray / LA-2 switch), no Mix, no side-chain filter beyond Emphasis, no
  external side chain: this is the faithful version. The ratio figures are approximate and program
  dependent by design.
- CPU: one log and one pow per channel every 8 samples; the rest is a handful of multiplies. Light.

## Build

    python3 tools/build.py plugins/uP2no2A
    .sdk-tools/host_sim plugins/uP2no2A/build/native/up2no2a.dylib test --wav plugins/uP2no2A/build/test.wav

The skin in `skins/` is generated by `skin_tools/make_skin.py` (needs Pillow; re-run it after
changing the layout, then rebuild). `--preview file.png` writes a picture of both pages.
